# PXL Spring 0.9.1

Documentation release for **PXL Spring** — the contributing guide now states what the repository takes: issue reports and suggestions, reviewed and applied by the maintainer. Built against [PXL](https://github.com/hclimkr/pxl) 0.9.2, unchanged from 0.9.0.

Pre-1.0 release: documentation only, with no API or behavior change.

## Highlights

  - **Contributing policy**: `CONTRIBUTING.md` / `CONTRIBUTING_ko.md` state that the repository accepts issue reports and suggestions only — pull requests are not accepted, and the maintainer reviews each issue and makes the change
  - **What to include in a report**: the PXL Spring version and artifact (`pxl-spring-javax` / `pxl-spring-jakarta`), the Java and Spring (or Spring Boot) versions, expected versus actual behavior with the exception message, and a minimal reproduction — the annotated DTO plus the controller method or `PxlSpring` builder chain
  - **Vulnerabilities stay private**: security reports are pointed at `SECURITY.md` rather than public issues
