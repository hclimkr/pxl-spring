# PXL Spring 0.9.0

First public release of **PXL Spring** — the Spring web layer for [PXL](https://github.com/hclimkr/pxl), handling multipart uploads and download responses while PXL does the binding. Built against PXL 0.9.2.

Pre-1.0 release: feature-complete and fully tested, with the API still open to refinement before `1.0.0`.

## Highlights

  - **Import**: multipart uploads (XLSX · XLS · CSV) → Java objects
  - **Export**: Java objects → Excel · sample Excel · multi-workbook ZIP, sent to a stream, a file, or a download response
  - One `PxlSpring` bean fronting five fluent entry points, with Bean Validation, RFC 5987 download names, and opt-in AOP performance logging
