# Security Policy

## Supported Versions

PXL Spring is pre-1.0; security fixes are applied to the latest released version only.

| Version | Supported          |
|---------|--------------------|
| 0.9.x   | ✅ |
| < 0.9   | ❌ |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately through GitHub's
[private vulnerability reporting](https://github.com/hclimkr/pxl-spring/security/advisories/new)
(the **Security** tab → **Report a vulnerability**). If that is unavailable, email
the maintainer at hclim.kr@gmail.com.

Please include as much of the following as you can, to help us assess the report quickly:

- The affected version(s) and artifact (`pxl-spring-javax` or `pxl-spring-jakarta`).
- A description of the vulnerability and its impact.
- Steps to reproduce, or a minimal proof of concept.
- Any known mitigations or workarounds.

### What to expect

- We aim to acknowledge a report within a few business days.
- We will keep you informed of the progress toward a fix and public disclosure.
- Once a fix is released, we are happy to credit you in the release notes unless
  you prefer to remain anonymous.
