# Contributing Guide

Thank you for your interest in PXL Spring.

**This repository accepts issue reports and suggestions only.**

If you find a bug or have an idea for an improvement, please
[open an issue](https://github.com/hclimkr/pxl-spring/issues) — the maintainer will review it
and make the change. Pull requests are not accepted.

---

## Reporting an Issue

The more concrete the report, the faster it can be addressed. Where possible, include:

- The PXL Spring version and artifact (`pxl-spring-javax` or `pxl-spring-jakarta`), and your
  Java and Spring (or Spring Boot) versions.
- What you expected versus what actually happened (with the exception message / stack trace).
- A minimal reproduction — the annotated DTO plus the calling code (the controller method or
  the `PxlSpring` builder chain). If a source file is needed to reproduce it, attach a trimmed
  one with any sensitive data removed.

For library usage, see [README.md](README.md).

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public issues.
Follow [SECURITY.md](SECURITY.md) instead.
